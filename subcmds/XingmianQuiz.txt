# XingmianQuiz  (XingmianQuiz-1.0.0.jar)
## 注册指令
  /quiz  usage='/quiz <reload|now|info>' desc='星冕答题管理命令' alias=None perm='xingmian.quiz.admin'

## 代码类
  cn.xingmian.quiz.QuizCommand

## javap 字符串 token
  info now reload reloaded

## 文本资源里的帮助/用法行
  · # 星冕答题 · 配置
  · # 改完在游戏里执行 /quiz reload 即可生效，不用重启服务器。
  · # 题库文件是 plugins/XingmianQuiz/questions.yml
  · # 出题间隔（秒）。1800 秒 = 30 分钟。
  · # 注意：下一题永远按这个间隔出，不受答题情况影响。
  · # 每道题的作答时限（秒）。到点没人答对就广播「没人答出」并公布答案。
  · # 60 = 每题给 1 分钟；设成 0 或负数 = 不限时（挂到下一题出现为止）。
  · # 如果希望「一有人答对就换个时间重新计时」，把下面这项设成 >= 0 的秒数：
  · #   -1  = 关闭（保持上面的固定节奏，每 30 分钟一题）  ← 默认
  · #   20  = 有人答对后 20 秒就出下一题
  · # 服务器启动后，第一次出题前等待多少秒。
  · # 答对一题奖励多少星点（Vault 经济，就是平时显示在余额里的那个「星点」）。
  · # 服务器里一个玩家都没有时，是否暂时不出题（有人了再出）。
  · #   true  = 没人在线不出题（推荐：避免白白浪费题目）
  · #   false = 不管有没有人都按时出题
  · # 上一个开关打开时，没人在线要隔多少秒检查一次。
  · # 题库文件名（相对 plugins/XingmianQuiz/ 目录）。
  · # 界面与提示文案
  · prefix: '&6&l[星冕答题] &r'
  · question: '&f题目：&e{question}'
  · hint: '&7在聊天框直接输入答案，限时 &e{time} &7秒，第一个答对的玩家得 &6{reward} &7星点'
  · correct: '&a玩家 &e{player} &a第一个答对了！答案：&f{answer} &7· 奖励 &6{reward} &7星点'

  · no-economy: '&c经济系统不可用，奖励发放失败，请联系管理员。'

  · info-header: '&6===== 星冕答题 ====='
  · info-current: '&7当前题目：&f{question}'
  · info-answer: '&7标准答案：&f{answer}'
  · info-status-asking: '&7状态：&e答题中，等待玩家作答'
