  · # 森罗厨房图鉴 - 配置文件
  · # 条目格式: "kaleidoscopecookery:物品id|显示名"
  · # 解锁条件：玩家亲手从 KC 制作方块/家具上取下成品（炒锅/汤锅/蒸笼/沙威玛/磨盘/
  · #          砧板/茶壶/茶杯垫…），或在合成台做出该物品
  · # 改完配置执行 /cookbook reload 生效
  · # 产出追踪：玩家与 KC 方块/家具交互后，比对"交互前 / 交互后"的背包，
  · # 多出来的图鉴内菜品即判定为本次自己产出。
  · # 为什么需要它：KC 的茶壶、茶杯垫是 CraftEngine 家具（不是方块），
  · # 蒸笼正常取熟食也不发任何 KC 事件——这些通路只能靠这条链路捕获。
  · # 采集点在 CE 的方块/家具交互事件里（它们都在"给物品之前"触发），
  · # 所以拍到的基线是干净的；玩家互送菜、从箱子取菜都不经过这个点，不会被误记。
  · # 只追踪该命名空间内的方块/家具（KC 的东西全在这个命名空间下）
  · # 采样延迟（tick）：CE 在事件 fire 之后才真正把物品给到玩家，必须延后采样。
  · # 两个采样点兼顾"立刻给"和"下一拍才给"两种情况。
  · # 排除的方块/家具：展示架/厨具架/果篮这类"可以放别人成品再取下"的载体，
  · # 避免玩家把别人做的菜放上去再拿下来刷图鉴。
