  · # 高通滤波器
  · # 滤掉截止频率以下的低频轰鸣声。
  · # 真实扩音器一般会把 300Hz 以下的声音全部切掉。
  · highpass-freq: 300.0        # 截止频率（Hz），范围 50 – 20000
  · # 低通滤波器
  · # 滤掉截止频率以上的高频嘶声。
  · # 保留真实扩音器那种"闷在盒子里"的音色。
  · lowpass-freq: 4500.0        # 截止频率（Hz），范围 50 – 20000
  · # 存在感均衡（EQ 峰值）
  · # 提升一个窄频段，让声音更清晰、更有"喇叭味"。
  · peak-freq: 2000.0           # 中心频率（Hz），范围 100 – 8000
  · peak-gain-db: 8.0           # 增益（dB），范围 -24 – +24
  · peak-q: 1.0                 # 滤波器宽度：Q 越大频段越窄（0.1 – 10）
  · # 失真（软饱和）
  · # 加入类似喇叭过载的谐波破音。
  · # 采用 tanh 软削波：drive 1.0 = 干净，3.0 = 明显破音。
  · distortion-drive: 2.2       # 软削波前的预增益（0.1 – 5.0）
  · # 背景噪声
  · # 叠加一层轻微的白噪声，营造真实环境感。
  · noise-level: 0.008          # 噪声振幅 0.0 – 1.0（0.005 – 0.02 比较自然）
  · # 混响（Schroeder）
  · # 加入一点房间反射音。默认关闭——在空旷的 Minecraft 环境里
  · # 容易让语音变得发糊。
  · reverb-wet: 0.22            # 干湿比：0.0（全干）– 1.0（全湿）
