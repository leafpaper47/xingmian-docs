## 文本资源里的帮助/用法行
  · # 栓玩家插件配置
  · # 超过这个距离，被栓玩家开始被拽向主人（单位：格）
  · # 超过这个距离，绳子断裂（单位：格）
  · # 拉拽冲量，越大拉得越狠（0.1 ~ 1.0 之间比较合理）
  · # 拉拽时附加的向上速度，帮助被栓玩家翻过小坎
  · # 逻辑执行间隔（tick），越小越顺滑也越吃性能
  · # 是否允许用剪刀右键割断绳子
  · # 每拴住一个玩家是否消耗手里的那根栓绳（原版栓动物是消耗的）
  · # 绳子被拉断时是否把栓绳掉在地上（原版断绳会掉）
  · # 触发方式开关：想用哪种就留 true
  · # 手持栓绳右键玩家即可栓住
  · # 允许用 /leash <玩家> 命令栓住
  · # 主人或被栓玩家传送时是否保留绳子（false = 传送即断开）
