## 文本资源里的帮助/用法行
  · #  护甲耐久强化  ArmorUnbreaking
  · #  作用：护甲每要掉一次耐久（不论这次损耗是来自被打、被伤害吸收
  · #        吃掉的、还是荆棘反伤……），都按耐久附魔的概率判定
  · #        「这一次是否整个免掉」。不区分损耗来源。
  · #  最终豁免率 = min( level/(level+1), max-immunity )
  · #        耐久 I   → 50.0% 豁免（只掉 1/2，寿命 ×2）
  · #        耐久 II  → 66.7% 豁免（只掉 1/3，寿命 ×3）
  · #        耐久 III → 75.0% 豁免（只掉 1/4，寿命 ×4）   ← 按需求锚定在这一档
  · #        耐久 IV  → 80.0% 豁免（只掉 1/5，寿命 ×5）
  · #        耐久 V   → 83.3% 豁免（只掉 1/6，寿命 ×6）
  · #        耐久 X   → 90.9% 豁免（只掉 1/11，寿命 ×11）
  · #  想看实时概率表：游戏里敲 /armordura table
  · # 豁免率上限（0~1）。默认 0.9091 = 十级那条线的值，等于不额外封顶。
  · # 若觉得十级太耐用，把它调小即可，例如：
  · #   0.75  → 耐久 III 及以上统统封顶在「只掉 1/4」（寿命 ×4）
  · #   0.80  → 封顶在「只掉 1/5」（寿命 ×5）
  · # 是否补偿原版护甲自带的那层豁免（原版 = 2L/(5L+5)，耐久三只有 30%）。
  · # 原版环境保持 true —— 插件会把那 30% 算进去，让最终总概率正好等于上表。
  · # ⚠ 只有当服务器用别的手段（数据包/其它插件）把护甲豁免概率改掉之后，
  · #   才改成 false，否则会重复补偿、比上表更强。
  · # 打开后每次耐久扣减都打印一行判定过程（排查用，平时关掉）
  · description: 让护甲上的耐久附魔按 L/(L+1) 概率豁免耐久扣减（覆盖全部损耗来源）
  · description: 护甲耐久强化 - 查看概率表 / 重载配置
  · usage: /armordura <table|reload>
  · description: 允许使用 /armordura
