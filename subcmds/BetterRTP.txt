  · RtpOnFirstJoin: # 将以控制台身份执行以绕过延迟
  · Enabled: false # 玩家首次加入服务器时是否执行随机传送
  · World: 'world' # 首次随机传送的目标世界
  · SetAsRespawn: false # 将此次随机传送位置保存为玩家的新出生点
  · Enabled: true # 启用或禁用冷却计时器
  · LockAfter: 0 # 在 # 次随机传送后将玩家锁定为永久冷却（0 为禁用）
  · Time: 180 # 单位：秒
  · PerWorld: false # 是否按各世界单独处理冷却？如果禁用，玩家在原冷却结束前无法在其他世界随机传送
  · ## 执行命令与实际随机传送之间的间隔时间，单位为秒。设为 "0" 可禁用延迟计时器 #
  · Enabled: true # 允许 BetterRTP 在玩家执行 `/rtp` 之前自动排队预生成安全随机传送位置
  · Enabled: true # 将所有随机传送相关日志记录到 log.log 文件
  · ## "Biomes: []" 表示允许所有生物群系！ #

  · ## 如果上方 "UseWorldBorder" 设为 true，中心 X 和 Z 将被忽略！ #
  · ## BetterRTP 不会传送到的方块。更多方块见：https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Material.html #

  · ## [MaxRadius] 和 [MinRadius] 必须为正数！且两者不能相等！
