# PVPPlugin  (PVPPlugin-1.2.28.jar)
## 注册指令
  /pvp  usage='/pvp [bet|spectate|accept|deny|team|seta|setb|reload|help|rank(join|spectate|cancel|top|stats|season|claim)]' desc='PVP 决斗主命令' alias=['duel'] perm=None

## 文本资源里的帮助/用法行
  · # ============ PVPPlugin 配置文件 ============
  · # 修改后可使用 /pvp reload 重载（管理员）
  · # 邀请超时（秒），超时未回应自动拒绝
  · # 准备期（秒）：接受后传送+下注窗口
  · # 战斗时长（秒），默认 180 = 3 分钟
  · # 掉线重连等待（秒），默认 180 = 3 分钟；超时判负
  · # 观众下注固定金额
  · # 竞技场世界名（默认 pvp_arena；填 "" 或 "*" 则允许任意世界就地战斗，但强烈建议专用竞技场世界）
  · # 竞技场区域半径（方块），决斗中玩家离开此范围会被拉回
  · # 是否必须设置竞技场 A/B 点才允许开始决斗（false=未设点时就地战斗）
  · # 竞技场 A 点坐标（使用 /pvp seta 站在目标位置保存；也可手动填写 world/x/y/z/yaw/pitch）
  · # 竞技场 B 点坐标（使用 /pvp setb 保存）
  · # 是否启用团战模式（/pvp team create <A人数>:<B人数>）
  · # ============ 公平排位模式 ============
  · # 是否启用公平排位（/pvp rank）
  · # 排位世界名（请与服务器实际排位世界一致，如 pvpgame）
  · # 排位入场费（星点），发起与加入各扣一次，无论胜败均不退还
  · # 发起后等待对手加入的秒数，超时自动取消并退还发起者入场费
  · # 双方到齐后开战倒计时（秒）
  · # 每局段位分变动（胜 +score-step / 负 -score-step，下限 0）
  · # 排位中死亡后的复活缓冲（秒）：死亡玩家将复活在排位世界（pvpgame）出生点，
  · # 倒计时结束后自动传送回死亡前原位置；设为 0 则复活后立即回原位置
  · # ============ 公平排位 · 赛季排行与奖励 ============
  · # 每个自然月为一个赛季（每月1号 ~ 月末23:59:59），跨月自动封盘开启新赛季；
  · # 月末按 ①胜场多 ②结算时当前段位高(score) ③胜率高 ④击杀多 ⑤死亡少 排序取前三名，
  · # 前三名各获得 1 份皮肤卷轴奖励，通过界面 /pvp rank claim 自行领取（每赛季每人限领1次，
  · # 先清点背包空格、无空格禁止发放；跨月后旧赛季未领奖励作废）。
  · # 是否启用赛季排行与奖励功能（/pvp rank season / claim）
  · # 赛季奖励皮肤 ID（发给 /yiyunceskin give <此ID> <玩家名>）
  · # 决斗期间 / 竞技场世界内拦截的命令（前缀匹配，不要带 /）
  · # ============ 公告文案模板（支持 & 颜色代码） ============
