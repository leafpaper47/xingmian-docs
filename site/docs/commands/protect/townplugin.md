# 城镇 · TownPlugin

> 分类 🔒 领地与保护 · 版本 `1.4.6-title` · 指令 5 条 · api-version `1.21`

::: tip 星冕服自研城镇系统，聚落建城与城镇管理
这是星冕服务器自研的城镇系统，把玩家聚落做成可升级的行政实体：从聚落、乡镇、城镇一路升到王都，靠繁荣度推进，并配套债券、贷款、多物品任务、缴纳面板、丰收节、城镇传送、执政官称号和城镇仓库。它同时承担了保护与社交入口的角色，玩家建城、加入城镇、存取共享物资、传送走访都在这里完成。经济与权限部分通常要和服内的经济、权限插件配合使用。
:::

## 什么时候会用到它

- 玩家想建自己的聚落并逐步升级成乡镇、城镇乃至王都时
- 管理员需要查看或干预某个城镇的数据、清理城镇仓库时
- 玩家想进本城镇的共享仓库存取公共物资时
- 玩家想浏览全服各城镇的传送点并直接传送过去时
- 城镇需要发债券、放贷款、挂任务或开缴纳面板收资源时

## 上手流程

1. 先确认玩家有 town.use 权限（默认已给），然后让玩家执行 /town 打开城镇主界面，熟悉创建与加入入口
2. 建城或加入城镇后，用 /wh 打开所属城镇的共享仓库，验通货仓与权限是否正常
3. 管理员给自己或管理组加 town.admin 权限，再用 /townadmin 进管理面板做配置与数据维护
4. 玩家之间走动时用 /townwarp 看全服城镇传送点，确认传送点已建好再让新人使用
5. 具体按钮位置与子指令请先在游戏内各界面和 help 里对一遍再写进服规

## 指令详解

### `/town` — 打开城镇核心界面，进城镇系统的总入口

- **语法**：`/town`

- **示例**：

```
/town
```

- **别名**：`/tw`
- **备注**：别名 /tw。界面里的具体按钮与后续参数以游戏内实际显示为准，本手册不臆测。

### `/townadmin` — 打开城镇管理面板，供管理员配置与维护城镇数据

- **语法**：`/townadmin`

- **示例**：

```
/townadmin
```

- **别名**：`/twa`
- **备注**：别名 /twa。需要 town.admin 权限（默认 op），普通玩家打开会被拒。面板内的具体选项以游戏内为准。

### `/townui` — 直接打开城镇创建界面，方便新玩家建城

- **语法**：`/townui`

- **示例**：

```
/townui
```

- **别名**：`/twu`
- **备注**：别名 /twu。和 /town 是不同入口，创建相关操作优先用这个界面。

### `/townwarp` — 查看并传送到各城镇的传送点

- **语法**：`/townwarp`

- **示例**：

```
/townwarp
```

- **别名**：`/twarp`
- **备注**：别名 /twarp。全服玩家可用，前提是对应城镇已经设置好传送点。

### `/wh` — 打开所属城镇的共享仓库

- **语法**：`/wh`

- **示例**：

```
/wh
```

- **备注**：必须先加入城镇，否则打不开。仓库是整镇共享的，取放前提醒玩家留意公共物资。

## 注意事项

::: warning
- 具体参数与子指令以游戏内 help 和界面提示为准，升级、债券、贷款、任务、缴纳等操作多走 GUI，不要凭猜输入参数
- 清理任意城镇仓库属于高危操作，只给可信管理组 town.warehouse.clear 权限
- 城镇共享仓库是全镇可见的公共空间，动权限或清仓前先在服内公告，避免物资纠纷
- 升级到更高等级通常要求繁荣度达标，调数值前先备份城镇数据文件
:::

## 权限节点

| 节点 | 说明 | 默认 |
| --- | --- | --- |
| `town.admin` | 城镇系统管理权限 | op |
| `town.use` | 允许使用城镇功能 | True |
| `town.warehouse.clear` | 城镇仓库清理权限（清理任意城镇仓库） | op |
