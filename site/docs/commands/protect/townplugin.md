# TownPlugin

> 版本 `1.4.6-title` · 指令 5 条 · api-version `1.21` · 文件 `TownPlugin-1.4.6-title.jar`

星冕服务器城镇系统（聚落/乡镇/城镇/王都 繁荣度升级、债券、贷款、多物品任务、缴纳面板、丰收节、城镇传送、执政官称号、城镇仓库）

::: tip 用法提示
本页数据由服务器上该插件 jar 内的 `plugin.yml` 自动解析生成，只包含**指令名、说明、用法格式、别名与权限节点**。
具体子参数可以执行 `/town help` 或该插件对应子命令的 `help` 查看。
:::
