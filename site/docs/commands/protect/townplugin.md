# 城镇 · TownPlugin

> 分类 🔒 领地与保护 · 版本 `1.4.8-itemguard` · 指令 5 条 · api-version `1.21`

::: tip 城镇系统
星冕自研城镇：创建城镇、招募成员、城镇仓库、银行债券与繁荣度，全流程走 GUI，命令只是入口。
:::

## 常用用法

| 场景 | 指令 | 说明 |
| --- | --- | --- |
| 玩家开城镇界面 | /town | 别名 /tw；一切操作都在界面里点 |
| 没城镇的人去创建 | /townui | 创建要 600 星辉 + 1 张标志性建筑凭证 |
| 传送去某个城镇 | /townwarp | 列表里选城镇传送点，免费次数用完要花繁荣度 |
| 开城镇共享仓库 | /wh | 必须在 world 世界，其它世界会被拦 |

## 指令一览

| 指令 | 功能 | 用法 | 权限节点 |
| --- | --- | --- | --- |
| `/town` | 打开城镇核心界面（信息/成员/银行/任务）<br>别名 `/tw` | `/town` | — |
| `/townadmin` | 城镇管理面板：审批申请、封存/删除城镇<br>别名 `/twa` | `/townadmin` | — |
| `/townui` | 打开创建城镇界面<br>别名 `/twu` | `/townui` | — |
| `/townwarp` | 查看并传送至各城镇传送点<br>别名 `/twarp` | `/townwarp` | — |
| `/wh` | 打开所属城镇的共享仓库 | `/wh` | — |

## 指令详解

### `/town` — 打开城镇核心界面（信息/成员/银行/任务）

- **语法**：`/town`

- **示例**：

```
/town
```

- **别名**：`/tw`
- **备注**：别名 /tw；没加入城镇时界面里会引导创建或申请加入

### `/townadmin` — 城镇管理面板：审批申请、封存/删除城镇

- **语法**：`/townadmin`

- **示例**：

```
/townadmin
```

- **别名**：`/twa`
- **备注**：别名 /twa；需 town.admin

### `/townui` — 打开创建城镇界面

- **语法**：`/townui`

- **示例**：

```
/townui
```

- **别名**：`/twu`
- **备注**：别名 /twu；名字 1–5 字，消耗 600 星辉与 1 张建筑凭证

### `/townwarp` — 查看并传送至各城镇传送点

- **语法**：`/townwarp`

- **示例**：

```
/townwarp
```

- **别名**：`/twarp`
- **备注**：别名 /twarp；设置传送点前 2 次免费，之后每次 100 繁荣度

### `/wh` — 打开所属城镇的共享仓库

- **语法**：`/wh`

- **示例**：

```
/wh
```

- **备注**：只在 world 世界可用（配置项 warehouse-world），且需先加入城镇

## 子指令速查

| 子指令 | 功能 | 示例 |
| --- | --- | --- |
| `/townadmin accept <城镇>` | 通过某城镇的创建/入盟申请 | `/townadmin accept 星落镇` |
| `/townadmin deny <城镇>` | 驳回申请 | `/townadmin deny 星落镇` |
| `/townadmin delete <城镇>` | 删除城镇并释放其数据（慎用） | `/townadmin delete 星落镇` |

## 注意事项

::: warning
- delete 是硬删除：城镇仓库、成员关系、债券全部一起没，先确认能接受。
- 玩家「/wh 打不开」九成是人在别的世界，不是权限问题。
- 传送到期/封存城镇要 100 星辉重新激活，激活后繁荣度回落到 60。
:::

## 权限节点

| 节点 | 说明 | 默认 |
| --- | --- | --- |
| `town.admin` | 城镇系统管理权限（审批、删除） | op |
| `town.use` | 使用城镇功能（默认开启） | True |
| `town.warehouse.clear` | 清理任意城镇仓库（高危） | op |
