# 镜像方块 · Mirrora

> 分类 🗺️ 世界与地图 · 版本 `1.2.1` · 指令 1 条 · api-version `1.21`

::: tip 镜像方块插件
Mirrora 用来做“镜像方块”效果：设定好一块区域后，插件会把那边的方块按镜像关系同步到另一侧，常见于对称建筑、双塔、城堡大门这类左右一致的造景。
:::

## 常用用法

| 场景 | 指令 | 说明 |
| --- | --- | --- |
| 建镜像区域 | /mirror | 按提示框选两点 |

## 指令一览

| 指令 | 功能 | 用法 | 权限节点 |
| --- | --- | --- | --- |
| `/mirror` | 管理镜像区域，按提示设定区域并执行镜像 | `/mirror` | `mirrora.admin` |

## 指令详解

### `/mirror` — 管理镜像区域，按提示设定区域并执行镜像

- **语法**：`/mirror`

- **示例**：

```
/mirror
```

- **权限**：`mirrora.admin`
- **备注**：这是本插件唯一的入口指令，具体要跟哪些子参数由插件运行时提示决定；不确定时以游戏内 help 提示为准。权限节点 mirrora.admin，默认仅 op 可用…

## 注意事项

::: warning
- 具体参数与子指令以游戏内 help 为准，本手册不臆测未公开的写法
- 镜像会批量改动方块，第一次用建议在测试服或先备份世界存档，再上正式服
- 镜像区域不会被自动保护，务必配合 WorldGuard / Residence 圈地，防止玩家在镜像区建房或挖矿
:::
