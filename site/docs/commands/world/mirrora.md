# 镜像方块 · Mirrora

> 分类 🗺️ 世界与地图 · 版本 `1.2.1` · 指令 1 条 · api-version `1.21`

::: tip 镜像方块插件，把一块区域的建筑按轴镜像复制
Mirrora 用来做“镜像方块”效果：设定好一块区域后，插件会把那边的方块按镜像关系同步到另一侧，常见于对称建筑、双塔、城堡大门这类左右一致的造景。它只负责方块层面的镜像，不参与领地保护，通常和 WorldGuard、Residence 一起用，把镜像区域圈进领地防止玩家破坏。
:::

## 什么时候会用到它

- 建造对称建筑：先做好一侧，用镜像把另一侧自动补齐，省掉重复劳动
- 维护对称结构：一侧被炸或被破坏后，靠镜像把另一边恢复成一致
- 做仪式感造景：中心线两侧需要严格对称的塔楼、走廊、庭院
- 修复手滑：一侧修改后另一边不同步，用镜像重新对齐

## 上手流程

1. 先确认服务端已加载 Mirrora，并给自己 mirrora.admin 权限（op 默认就有）
2. 进游戏输入 /mirror 看插件给出的提示，按提示确定镜像区域的边界与镜像轴方向
3. 设定好区域后触发一次镜像，先在单机/测试服小范围试，确认方向没搞反
4. 正式使用前把镜像区域圈进 WorldGuard 或 Residence，避免被其他玩家改动

## 指令详解

### `/mirror` — 管理镜像区域，按提示设定区域并执行镜像

- **语法**：`/mirror`

- **示例**：

```
/mirror
```

- **权限**：`mirrora.admin`
- **备注**：这是本插件唯一的入口指令，具体要跟哪些子参数由插件运行时提示决定；不确定时以游戏内 help 提示为准。权限节点 mirrora.admin，默认仅 op 可用。

## 注意事项

::: warning
- 具体参数与子指令以游戏内 help 为准，本手册不臆测未公开的写法
- 镜像会批量改动方块，第一次用建议在测试服或先备份世界存档，再上正式服
- 镜像区域不会被自动保护，务必配合 WorldGuard / Residence 圈地，防止玩家在镜像区建房或挖矿
- 执行前确认镜像轴方向，方向设错会把建筑复制到意料之外的位置
:::
