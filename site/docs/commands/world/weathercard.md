# 天气卡 · WeatherCard

> 分类 🗺️ 世界与地图 · 版本 `1.0.10` · 指令 1 条 · api-version `1.21`

::: tip 四张扑克天气卡
这是星冕服自研的天气卡插件，提供黑桃夜、红桃昼、梅花雨、方片晴四种扑克牌形态的消耗品，玩家用一张就能把当前天气切成对应状态。
:::

## 指令详解

### `/weathercard` — 天气卡管理指令：给玩家发放指定类型和数量的天气卡

- **语法**：`/weathercard give 玩家名 卡牌类型 数量`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `玩家名` | 必填 | 要发给谁，填在线玩家名 |
| `卡牌类型` | 必填 | 写具体卡名，对应黑桃夜、红桃昼、梅花雨、方片晴，可填写法以游戏内 Tab 补全为准 |
| `数量` | 必填 | 发放几张，正整数 |


- **示例**：

```
/weathercard give Steve 梅花雨 1
/weathercard give Steve 方片晴 5
```

- **别名**：`/wcard`
- **备注**：别名 wcard，权限节点 weathercard.give；玩家要真正用卡还需 weathercard.use。卡牌只能在家园世界和星陨之地使用，一次消耗一张…

## 注意事项

::: warning
- 具体参数与子指令以游戏内 help 为准，本插件为星冕自研，参数取值随版本可能调整，文档只写已确认的用法
- 卡牌类型不是自由填写的文字，写错了不会发出去，发之前先用 Tab 补全确认可用写法
- 卡牌只在 家园世界 与 星陨之地 生效，别在世界外测试后以为插件坏了
:::

## 权限节点

| 节点 | 说明 | 默认 |
| --- | --- | --- |
| `weathercard.give` | 允许发放天气卡 | op |
| `weathercard.use` | 允许使用天气卡 | op |
