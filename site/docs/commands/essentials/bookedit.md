# 成书编辑 · BookEdit

> 分类 🧰 基础工具 · 版本 `2.0` · 指令 1 条 · api-version `1.21`

::: tip 成书排版与作者信息编辑小工具
解决服务器里书只能写纯白字、署名甩不掉的问题：玩家在书里用标签写颜色和效果，做出彩色带样式的说明书或古籍。同时提供两个快捷开关，把书的作者改成匿名、或把整本书标记为破旧外观。常和权限插件配合，决定谁能用这套编辑功能。
:::

## 什么时候会用到它

- 给玩家发一本带颜色和加粗标题的玩法说明书，比纯文本告示更醒目
- 做剧情任务道具时把书作者改成匿名，不让玩家看出是管理员写的
- 把线索书设为破旧外观，伪装成遗迹或 NPC 手里捡到的旧古籍
- 活动结束后清理署名，避免玩家从作者名反查出管理员的马甲账号

## 上手流程

1. 确认服务器已装 BookEdit，并给需要的玩家或权限组 bookedit.use（默认已对所有玩家开启）
2. 让玩家手持自己写好的成书（不是书与笔），输入 /book 看可用选项
3. 执行 /book anonymous 改作者、/book tattered 改外观，然后打开书本界面确认效果
4. 若玩家反馈没反应，先查是否手持成书、是否是本人署名的书，再查权限节点

## 指令详解

### `/book` — 改书作者为匿名，或把书设为破旧外观

- **语法**：`/book anonymous｜tattered｜help`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `选项` | 必填 | anonymous 把作者改为匿名；tattered 把书设为破旧；help 查看帮助 |


- **示例**：

```
/book
/book anonymous
/book tattered
```

- **别名**：`/bookedit`
- **备注**：别名 /bookedit。需要 bookedit.use 权限（默认开启）。操作对象是当前手持的成书，不是书与笔。

## 注意事项

::: warning
- 具体参数与子指令以游戏内 help 为准，不同版本可能增删功能
- 只能改自己署名的成书；拿别人的书或书与笔通常不会有反应
- 作者改匿名和设破旧都是直接写进物品数据的，改完一般没有一键还原，重要道具先备份
- 书里的颜色与效果标签写错会原样显示成乱码般的文字，给玩家写教程时最好附正确写法示例
:::

## 权限节点

| 节点 | 说明 | 默认 |
| --- | --- | --- |
| `bookedit.use` | 允许修改自己写的书（作者改匿名、设为破旧） | True |
