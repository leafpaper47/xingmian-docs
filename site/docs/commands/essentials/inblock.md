# 方块内藏身 · InBlock

> 分类 🧰 基础工具 · 版本 `1.0.0` · 指令 1 条 · api-version `1.21`

::: tip 自定义命令方块：右键方块执行指令
InBlock 用来把常用操作做成一枚可发放的方块物品，玩家像右键工作台一样右键这块方块，就能触发事先配好的指令或界面。它适合把活动领取、菜单入口、传送点之类的固定入口固化下来，交给玩家自己动手，省得管理员反复打字。具体能触发什么，取决于服里给这个方块写的配置。
:::

## 什么时候会用到它

- 活动发奖、每日签到这类固定入口，想让玩家自己右键方块领取，不用管理员手敲命令
- 给出生点、主城、商店街摆一个统一风格的入口方块，玩家右键即打开对应界面或执行指令
- 测试配置改动：改完方块定义后用重载指令刷配置，再给测试号发一块验证效果

## 上手流程

1. 先用 inb open 看看仓库界面，确认当前有哪些自定义方块及其定义
2. 用 inb give 把自己的测试号发一块目标方块，去空地上右键试效果
3. 改完配置执行 inb reload 重载，再发一块新的方块复测
4. 确认无误后再把发方块的权限或方块本身发给玩家

## 指令详解

### `/inb` — InBlock 主命令：打开仓库、发放自定义方块、重载配置

- **语法**：`/inb open 或 /inb give 玩家名 方块ID 数量 或 /inb reload`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `玩家名` | 必填 | give 子指令的目标玩家，需在线或可被服务端找到 |
| `方块ID` | 必填 | 要发放的自定义方块标识，具体取值以服内配置/仓库界面显示为准 |
| `数量` | 必填 | 发放份数，整数 |


- **示例**：

```
/inb open
/inb give Steve 活动入口 1
/inb reload
```

- **备注**：三个子指令分别对应不同权限节点，权限按大小写敏感记：Inblock.open、Inblock.give、Inblock.reload，默认仅管理员。方块ID 的合法取值在各服配置里不同，写错一般会被拒或发不出可用方块。

## 注意事项

::: warning
- 具体参数与子指令以游戏内 help 为准，方块ID 的命名各服不一样，不要照抄示例里的占位名字
- 权限节点区分大小写（Inblock.*），写错大小写等于没给权限，玩家会提示无权限
- 重载前先在测试号上验证改动，配置写错可能导致方块右键无反应
- 玩家手里残留的旧方块可能在重载后仍指向旧定义，必要时收回重新发放
:::

## 权限节点

| 节点 | 说明 | 默认 |
| --- | --- | --- |
| `Inblock.give` | 允许给予自定义方块物品 | op |
| `Inblock.open` | 允许打开仓库界面 | op |
| `Inblock.reload` | 允许重载配置 | op |
