# 控制台屏蔽 · ConsoleSpamFixReborn

> 分类 🛡️ 权限与底座 · 版本 `2.1.0` · 指令 1 条 · api-version `1.13`

::: tip 按规则屏蔽控制台重复报错刷屏
它把控制台里反复刷的同一条报错按配置过滤掉，避免日志被冲爆、TPS 被刷屏拖累、真正的错误被淹没。
:::

## 指令详解

### `/csf` — 插件主命令，用于重载配置和查看帮助

- **语法**：`/csf`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `子指令` | 可选 | 如 reload 重新加载配置、help 查看帮助，具体以游戏内反馈为准 |


- **示例**：

```
/csf
/csf reload
```

- **备注**：需要 csf.admin 权限（默认仅 OP）；过滤规则本质在配置文件里，命令只是让它重新读取

## 子指令速查

| 子指令 | 功能 | 示例 |
| --- | --- | --- |
| `reload` | 重新加载插件配置，让新的屏蔽规则立即生效 | `/csf reload` |
| `help` | 列出可用子指令与用法 | `/csf help` |

## 注意事项

::: warning
- 屏蔽规则按文本匹配，写得太宽（比如只写 ERROR）会把真正需要看的报错一起吞掉，建议尽量贴着完整句子写
- 它只是让控制台不再刷这条日志，报错背后的插件问题依然存在，别把屏蔽当成修好了
- 改完配置要重载或重启才生效，改完记得回控制台验证一次是否真的不刷了
:::
