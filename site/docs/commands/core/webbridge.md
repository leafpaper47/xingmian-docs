# 网页桥接 · WebBridge

> 分类 🛡️ 基础与权限 · 版本 `1.0.0` · 指令 1 条 · api-version `1.21`

::: tip 打通卫星地图网页聊天与游戏内聊天
这是星冕服务器配套的网页桥接插件，负责把卫星地图网页端的发言送进游戏，并把正版账号与网页身份绑定起来做名字校验。它需要和服务器自研的卫星地图网页端配合使用，单独装上不会产生可见效果。日常管理基本用不到它，只有在玩家反馈网页聊天发不出去、或者需要完成网页身份验证时才会接触到。
:::

## 什么时候会用到它

- 玩家在卫星地图网页上想发聊天，但网页提示未绑定或未验证，需要引导其进游戏完成绑定
- 处理网页端冒用他人游戏名发言的问题，要求玩家先通过验证码核验身份
- 排查网页聊天不显示在游戏内、或游戏内消息不同步到网页的情况
- 服主交接时确认网页桥接链路是否正常（网页与服务端是否连通）

## 上手流程

1. 先在网页端按页面提示获取一个验证码，注意它通常有时效，别放太久
2. 让玩家用本人游戏账号登录服务器，在游戏内执行 /mapverify 加验证码完成绑定
3. 看到绑定成功的提示后，回到网页刷新页面，确认已经能正常发言
4. 如果反复失败，先核对验证码是否过期或大小写/数字是否输错，再查服务端日志里网页桥接的报错

## 指令详解

### `/mapverify` — 在游戏内提交网页聊天绑定验证码，完成正版名核验

- **语法**：`/mapverify 验证码`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `验证码` | 必填 | 由卫星地图网页端生成并展示给你的一串字符，有时效，需原样输入 |


- **示例**：

```
/mapverify 8F3K2Q
```

- **备注**：验证码一般由网页端生成，先拿码再进游戏；过期就回网页重新获取。普通玩家自己执行即可，管理员不需要代跑。

## 注意事项

::: warning
- 这是星冕自研的桥接插件，具体参数与子指令以游戏内 help 为准，本文只覆盖已知的 /mapverify
- 验证码通常有时效性，网页生成后应尽快在游戏内使用，过期需重新获取
- 绑定关系按正版账号名核验，玩家改名或换号后可能需要重新验证，别直接手动改网页数据
- 网页聊天出问题时先分清是网页端还是服务端侧，不要急着重启整服，先看服务端日志里桥接相关报错
:::
