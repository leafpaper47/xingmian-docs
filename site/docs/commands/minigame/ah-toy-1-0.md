# 小玩具 · Ah-Toy-1.0

> 分类 🎲 小游戏与娱乐 · 版本 `1.0` · 指令 1 条 · api-version `26.1`

::: tip 趣味小玩具发放与配置管理插件
Ah-Toy 是「玩具商阿叶」主题的娱乐向小插件，独立配置文件，向玩家发放钩爪、斗蛐蛐这类与战斗平衡无关的趣味玩具。
:::

| 场景 | 指令 | 说明 |

| 发玩具给玩家 | /toy give 钩爪 Steve | 钩爪/斗蛐蛐等玩具 id |

## 指令详解

### `/toy` — 发放钩爪或斗蛐蛐玩具，或重载玩具配置

- **语法**：`/toy give （钩爪｜斗蛐蛐） [玩家]   或   /toy reload`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `give` | 可选 | 子指令：给玩家发放玩具 |
| `钩爪 / 斗蛐蛐` | 必填 | 玩具类型，二选一，需与配置文件里登记的玩具名一致 |
| `玩家` | 可选 | 目标玩家名，省略时一般默认给自己 |
| `reload` | 可选 | 子指令：重载本插件配置文件 |


- **示例**：

```
/toy give 钩爪 Steve
/toy give 斗蛐蛐
```

- **备注**：give 需要 ahtoy.command.give，reload 需要 ahtoy.command.reload，默认都只给 OP；玩具名写错会提示无效，具体…

## 注意事项

::: warning
- 本插件为自研/小众插件，具体参数与可用玩具名以游戏内 help 和插件配置为准，不要照搬其它服务器的写法
- give 与 reload 是两个独立权限节点，只给管理组发 give 时不要顺手把 reload 也开给普通玩家
- reload 只能重载本插件配置，改动了其它插件或服务端设置仍需正常重启
:::

## 权限节点

| 节点 | 说明 | 默认 |
| --- | --- | --- |
| `ahtoy.command.give` | 允许使用 /toy give 获取玩具 | op |
| `ahtoy.command.reload` | 允许使用 /toy reload 重载玩具配置 | op |
