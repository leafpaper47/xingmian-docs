# 知识问答 · XingmianQuiz

> 分类 🎲 小游戏与娱乐 · 版本 `1.0.0` · 指令 1 条 · api-version `1.21`

::: tip 定时自动百科答题，首个答对者得星点
这是星冕服自研的答题小游戏插件，服里每隔约 15 分钟自动出一道百科题，谁先在聊天里答对谁就拿到星点奖励。它负责出题、判题和发奖，星点本身通常由服内的点数或经济体系记账，因此常和星点相关的商店、兑换玩法一起用。插件本体只提供一个管理指令，日常运行基本不需要人工干预。
:::

## 什么时候会用到它

- 想给服务器加点轻量活动、让在线玩家有事可做时
- 开服初期人气不足，用答题这种零门槛玩法留住新玩家
- 作为星点奖励的一个来源，让玩家靠参与活动慢慢攒点数
- 需要临时手动触发一次答题、或答完想看看当前题目状态时

## 上手流程

1. 确认插件已随服务端启动加载，检查默认的出题间隔与题库配置是否符合预期
2. 让玩家知道玩法：题目会定时在聊天栏发出，直接在聊天框输入答案即可抢答
3. 用管理指令手动开一题做测试，确认能正常出题、判题、发星点
4. 根据测试结果调整配置后用重载指令生效，之后交给定时器自动跑

## 指令详解

### `/quiz` — 答题插件的管理指令，用于重载、立即出题和查看状态

- **语法**：`/quiz 子命令（reload、now、info）`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `子命令` | 必填 | reload 重载配置，now 立即出一道题，info 查看当前题目等信息 |


- **示例**：

```
/quiz info
/quiz now
/quiz reload
```

- **权限**：`xingmian.quiz.admin`
- **备注**：需要 xingmian.quiz.admin 权限，默认仅 OP 拥有。改完配置文件后用 reload 生效，避免直接重启整服。

## 注意事项

::: warning
- 这是星冕服自研插件，具体参数与子指令以游戏内 help 为准，输错子命令时看提示而不是凭猜测
- 重载只影响配置读取，正在进行的题目状态可能被重置，开题前先确认没有玩家正在抢答
- 答题奖励的星点依赖服内点数体系，如果发不出奖励先查对应的点数插件是否正常
- 别把 xingmian.quiz.admin 随便给普通玩家，否则他们可以反复手动出题刷奖励
:::
