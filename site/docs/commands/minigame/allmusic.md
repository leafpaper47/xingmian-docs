# 全服音乐 · allmusic

> 分类 🎲 小游戏与娱乐 · 版本 `4.0.2` · 指令 1 条 · api-version `1.13`

::: tip 全服音乐播放与广播的点歌类插件
AllMusic 把音乐播放做成了一个统一入口：管理员用一条指令就能给全服玩家起音乐，用来做开服氛围、活动暖场或公告配乐。插件本身说明很简略，只暴露了 /music 这个主指令，具体曲目与播放方式要靠游戏内 help 去看。它属于小众/自研类插件，常和服务器自己的资源包或音频分发方式配合使用。
:::

## 什么时候会用到它

- 开服、活动开场等需要给全服玩家统一放一段背景音乐的时候
- 节日活动、新人接待想临时营造气氛，但不想逐个玩家私发声音
- 刚接手服务器，想先摸清这个插件能用哪些曲目和玩法，用 /music help 看清单

## 上手流程

1. 先在服务端确认插件已正常加载（/plugins 列表里能看到 AllMusic，控制台无报错）
2. 进游戏用管理员身份执行 /music help，看清当前版本实际支持的子指令和曲目参数
3. 按 help 给出的格式试播一次，用另一个普通玩家客户端确认是否真的能听到
4. 把验证通过的曲目和写法记进活动流程，之后需要时直接广播

## 指令详解

### `/music` — 全服音乐主指令，查看帮助并进入播放功能

- **语法**：`/music help`

- **示例**：

```
/music help
```

- **备注**：聊天栏里显示的 [AllMusic]/music help 就是插件自带的用法提示；除 help 之外还有哪些子指令、曲目怎么传，以游戏内实际输出为准，不要照抄别服的写法。

## 注意事项

::: warning
- 具体参数与子指令以游戏内 help 为准，本手册不臆测未文档化的用法
- 全服音乐能否被听到取决于客户端是否拿到音频（资源包或音频分发），指令执行成功不等于玩家听得见，务必先在测试客户端验证
- 高峰期避免长时间循环播放，容易占用带宽并让低配客户端卡顿
- 授权时注意谁能用 /music，别让普通玩家拿到广播音乐的权限
:::
