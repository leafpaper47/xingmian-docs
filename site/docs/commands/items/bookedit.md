# 成书编辑 · BookEdit

> 分类 🎒 物品与合成 · 版本 `2.0` · 指令 1 条 · api-version `1.21`

::: tip 成书排版与作者信息编辑小工具
解决服务器里书只能写纯白字、署名甩不掉的问题：玩家在书里用标签写颜色和效果，做出彩色带样式的说明书或古籍。
:::

## 指令详解

### `/book` — 改书作者为匿名，或把书设为破旧外观

- **语法**：`/book anonymous｜tattered｜help`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `选项` | 必填 | anonymous 把作者改为匿名；tattered 把书设为破旧；help 查看帮助 |


- **示例**：

```
/book
/book anonymous
```

- **别名**：`/bookedit`
- **备注**：别名 /bookedit。需要 bookedit.use 权限（默认开启）。操作对象是当前手持的成书，不是书与笔。

## 注意事项

::: warning
- 具体参数与子指令以游戏内 help 为准，不同版本可能增删功能
- 只能改自己署名的成书；拿别人的书或书与笔通常不会有反应
- 作者改匿名和设破旧都是直接写进物品数据的，改完一般没有一键还原，重要道具先备份
:::

## 权限节点

| 节点 | 说明 | 默认 |
| --- | --- | --- |
| `bookedit.use` | 允许修改自己写的书（作者改匿名、设为破旧） | True |
