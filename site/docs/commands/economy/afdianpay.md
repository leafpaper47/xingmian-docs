# 爱发电支付 · AfDianPay

> 分类 🪙 经济与商店 · 版本 `1.1.7` · 指令 1 条 · api-version `1.13`

::: tip 把爱发电赞助自动换成游戏内奖励
AfDianPay 负责打通爱发电（afdian）赞助和服务器之间的链路：玩家点开赞助链接付款后，插件按订单把奖励发到游戏里。它主要和服务器经济、点券或礼包类插件配合，也是服主核对赞助记录、补发漏发奖励时的入口。适合用爱发电给服务器众筹、卖赞助位或卖点券的生存服与公益服。
:::

## 什么时候会用到它

- 玩家在爱发电赞助后一直没收到奖励，需要按订单号手动补发
- 想给全服或某个玩家发爱发电赞助链接，引导大家去支持服务器
- 核对自己的赞助订单有没有被插件正确读到、正确发奖
- 处理订单状态，把某笔赞助标记为已完成，避免重复发奖
- 从旧版本或旧数据表迁移过来，需要转换一次数据库结构

## 上手流程

1. 先确认插件已正常加载，并在配置里填好爱发电的用户 ID 和 API 令牌，保证能拉到订单
2. 进入游戏用管理员账号试一次完整流程：发链接、赞助一笔小额、看订单是否出现、奖励是否到账
3. 日常用订单查看指令核对到账情况，遇到漏发再用按订单号发奖的指令补上
4. 改完配置后用重载指令生效，改完数据结构才需要用数据库转换（务必先备份）

## 指令详解

### `/afDianPay` — 爱发电支付主指令，管理赞助链接、订单与奖励发放

- **语法**：`/afDianPay`

- **示例**：

```
/afDianPay
/afdian
```

- **别名**：`/afdian`
- **备注**：官方说明只写了插件名，没有给出子指令清单；实际功能按权限节点看分成发链接、查订单、按订单号发奖、完成订单、重载配置、转换数据库几块，具体写法以游戏内输入该指令后的提示为准

## 注意事项

::: warning
- 具体参数与子指令以游戏内 help 为准，别照抄别服的写法
- 按订单号发奖前一定先查订单，避免同一笔赞助重复发奖励
- 转换数据库会改动数据表结构，执行前必须先备份数据库或插件数据文件
- 爱发电侧的令牌不对或网络不通时，插件拉不到订单，奖励不会自动到账，先查控制台报错再手动补发
- 发赞助链接的权限默认对所有玩家开放，若不想让普通玩家乱发，需要在权限插件里收回该节点
:::
