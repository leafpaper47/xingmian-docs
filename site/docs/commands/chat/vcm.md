# 语音喇叭 · vcm

> 分类 💬 聊天与社交 · 版本 `0.1.1+26.2` · 指令 1 条 · api-version `26.2`

::: tip 语音喇叭
全服语音喇叭：把录好的语音/音效通过资源包广播给全服或指定玩家，常用于活动播报与整蛊彩蛋。
:::

## 常用用法

| 场景 | 指令 | 说明 |
| --- | --- | --- |
| 发一个语音喇叭 | /vcm give Steve | 把喇叭物品发给玩家，玩家自己用 |
| 改完配置生效 | /vcm reload | 音效清单改完要重载 |
| 打开管理界面 | /vcm manager | 查看已加载的音效与播放记录 |

## 指令一览

| 指令 | 功能 | 用法 | 权限节点 |
| --- | --- | --- | --- |
| `/vcm` | 语音喇叭主指令 | `/vcm <give｜reload｜manager>` | — |

## 指令详解

### `/vcm` — 语音喇叭主指令

- **语法**：`/vcm <give｜reload｜manager>`

- **示例**：

```
/vcm give Steve
```

- **备注**：命令名 vcm

## 子指令速查

| 子指令 | 功能 | 示例 |
| --- | --- | --- |
| `/vcm give <玩家> [数量]` | 发放语音喇叭物品 | `/vcm give Steve 3` |
| `/vcm reload` | 重载音效配置与资源索引 | `/vcm reload` |
| `/vcm manager` | 打开音效管理界面 | `/vcm manager` |

## 注意事项

::: warning
- 语音靠资源包下发，玩家没装/没重载资源包会听不到，别当 bug 查。
- 全服广播类音效别在跑图/战斗高峰刷，容易引发投诉。
:::

## 权限节点

| 节点 | 说明 | 默认 |
| --- | --- | --- |
| `vcm.admin` | 发放与重载（give / reload / manager） | op |
| `vcm.use` | 使用语音喇叭物品 | op |
