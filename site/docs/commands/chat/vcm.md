# 语音喇叭 · vcm

> 分类 💬 聊天与社交 · 版本 `0.1.1+26.2` · 指令 1 条 · api-version `26.2`

::: tip 语音扩音器：用喇叭向全场广播语音
这是 Simple Voice Chat 的附属插件，给服务器加了一个「扩音器」道具，玩家拿着它对着一片区域说话，附近（或全服）的人都能听见。它是已适配新版本并做过汉化的版本，指令入口统一收在 /vcm 管理面板里。它本身不产生语音通道，必须配合 Simple Voice Chat 和客户端语音模组一起才有效果。适合活动、开场致辞、指挥团战这类需要一个人对一群人讲话的场合。
:::

## 什么时候会用到它

- 开服活动、玩家聚会时，主持人用一个扩音器对全场讲话，不用挨个私聊或打字
- 大型团战、攻防活动里，指挥用扩音器统一喊指令，避免公屏刷屏
- 给活动奖励发放扩音器，作为限时道具或赞助者福利，控制谁能喊话
- 调试扩音器效果时，管理员临时给自己发一个道具进游戏实测音量与范围

## 上手流程

1. 先确认服务端已装好 Simple Voice Chat 本体，玩家客户端也装了对应语音模组并能正常通话
2. 进游戏用 /vcm 打开管理面板，看当前可用的子指令与扩音器状态
3. 按面板或 help 提示给自己或测试号发一个扩音器（权限节点描述里提到 give 这类管理子命令），拿在手上实测效果
4. 调完配置后用 reload 类管理子命令重载，再把 vcm.use 权限按需下发给玩家组

## 指令详解

### `/vcm` — 打开语音扩音器管理面板，所有子指令从这里进

- **语法**：`/vcm 子命令`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `子命令` | 可选 | 不带子命令时通常是打开面板或打印帮助；具体子命令以游戏内 help 输出为准 |


- **示例**：

```
/vcm
```

- **备注**：权限节点说明里提到 give（发放扩音器）和 reload（重载配置）这两个管理子命令，需要 vcm.admin；普通玩家使用扩音器只需 vcm.use。两个权限默认都是 op，记得手动下发给玩家组。

## 注意事项

::: warning
- 它是 Simple Voice Chat 的附属，本体没装或玩家客户端没有语音模组时，扩音器不会生效，排查问题先确认语音本体是否正常
- vcm.use 和 vcm.admin 默认都只给 op，开放给玩家前一定要用权限插件单独下发，否则玩家打不开也用不了
- 具体参数与子指令以游戏内 help 为准，不同版本（本包为 0.1.1 适配新版）子命令可能有增减，别照抄旧教程
- 改完配置记得重载或重启，并让玩家重新进服验证音量和范围是否按预期
:::

## 权限节点

| 节点 | 说明 | 默认 |
| --- | --- | --- |
| `vcm.admin` | 允许使用管理命令（/vcm give、/vcm reload） | op |
| `vcm.use` | 允许使用扩音器 | op |
