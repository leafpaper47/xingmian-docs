# 玩家邀请 · YaoqingPlugin

> 分类 💬 聊天与社交 · 版本 `1.0.0` · 指令 1 条 · api-version `1.21`

这是星冕服务器自研的「星友同行」拉新插件，用邀请码把新玩家和老玩家绑定成邀请关系，再按里程碑发放奖励。

## 指令详解

### `/yaoqing` — 打开「星友同行」邀请主界面

- **语法**：`/yaoqing`

- **示例**：

```
/yaoqing
/yq
```

- **别名**：`/yq`、`/邀请`
- **备注**：不需要任何参数，全部操作都在打开的图形界面里进行；别名 yq 和 邀请 等价。普通玩家需要 yaoqing.use（默认开启），管理类操作需要 yaoqing.…

## 注意事项

::: warning
- 这是星冕自研插件，具体参数与子指令以游戏内 help 和实际界面为准，本手册只覆盖已知的 /yaoqing 入口
- op 能看到的界面和普通玩家可能不同，测试时不要只用 OP 账号验证，要用普通玩家号走一遍
- 重置绑定或重算奖励属于不可逆操作，执行前先备份该插件的配置文件与数据文件
:::
