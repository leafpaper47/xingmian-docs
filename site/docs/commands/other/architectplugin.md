# 建筑师工具 · ArchitectPlugin

> 分类 📦 其他 · 版本 `1.3.7` · 指令 4 条 · api-version `1.21`

::: tip 星冕服务器的建筑师认证与接单系统
这是星冕服务器自研的建造生态插件，负责把「建筑师」做成一条可成长的身份线：玩家注册建筑师后接单建造、靠完成度与评价累积晋升进度，资深及以上还能进建材商店。玩家侧通过界面发布任务、加价、评价与申诉，管理员侧用独立界面处理系统任务、申诉和首席邀请。整套功能以 GUI 菜单为主，指令基本都是开界面的入口。
:::

## 什么时候会用到它

- 玩家想成为认证建筑师、查看自己的晋升进度与接单资格
- 玩家想发布建造委托、查看自己发布的任务、对完成质量评价或加价
- 资深建筑师或授权玩家采购建材
- 管理员处理申诉、派发系统任务、邀请首席建筑师、开关调试模式

## 上手流程

1. 先确认玩家已有 architect.use 权限（默认全体玩家开放），否则界面打不开
2. 玩家执行 /arch 完成建筑师注册，之后在这里查看认证状态、接单与晋升进度
3. 有建造需求时执行 /task 发布委托，任务进行中用同一界面加价或查看我的发布
4. 交付后在同一界面评价，出现纠纷则走申诉，由管理员在 /archadmin 处理
5. 晋升到资深或单独授予 architect.shop 后，执行 /archshop 进入建材商店

## 指令详解

### `/arch` — 打开建筑师主界面，注册认证、接单、看晋升进度

- **语法**：`/arch`

- **示例**：

```
/arch
```

- **备注**：玩家侧总入口，几乎所有玩家操作都在这个 GUI 里点，不需要额外参数

### `/archadmin` — 打开管理员界面，处理系统任务、申诉与首席邀请

- **语法**：`/archadmin`

- **示例**：

```
/archadmin
```

- **权限**：`architect.admin`
- **备注**：需要 architect.admin（默认仅 OP）；界面内含调试模式开关，改动前先在测试服确认效果

### `/archshop` — 打开建材商店，采购建造用材料

- **语法**：`/archshop`

- **示例**：

```
/archshop
```

- **备注**：进入条件为资深及以上身份，或被单独授予 architect.shop 权限；权限默认 op，需手动给非 OP 组开通

### `/task` — 打开玩家任务界面，发布委托、评价、申诉与加价

- **语法**：`/task`

- **示例**：

```
/task
```

- **备注**：面向所有有 architect.use 的玩家；发布、我的发布、评价、申诉、加价都在同一个界面里分页签操作

## 注意事项

::: warning
- 具体参数以游戏内 help 为准，本插件为服内自研，界面里的按钮与选项可能随版本调整
- architect.shop 默认是 op，仅靠「资深身份」并不能保证进门，需确认权限组已同步授予
- archadmin 属于管理员界面，调试模式会直接影响线上任务与申诉数据，改完记得关掉
- 任务发布、评价与申诉涉及玩家间经济与信誉纠纷，处理前先让玩家在 /task 里留下记录再动手
:::

## 权限节点

| 节点 | 说明 | 默认 |
| --- | --- | --- |
| `architect.admin` | 建筑师插件管理员 | op |
| `architect.shop` | 建材商店使用权（资深及以上默认可进，本权限用于单独开通） | op |
| `architect.use` | 使用建筑师插件 | True |
